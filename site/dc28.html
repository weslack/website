DEF CON 28 · August 2020 · SOHOplessly Broken

DC28

Our first outing, run remotely for the Safe Mode DEF CON. We took on the IoT Village SOHOplessly Broken CTF and walked away with six device flags.

  • 6 flags captured
  • 8 devices enumerated
  • 1 subnet (192.168.10.0/24)

We connected over the IoT Village OpenVPN from a shared Kali box (provisioned with Vagrant) and swept the subnet with nmap. From there it was mostly a hunt for known exploits and default credentials, a good introduction to how much consumer IoT ships wide open.

Flags captured

NUUO NVRmini

Captured

Unauthenticated command injection through a hidden debugging script gave a root shell. exploit-db/40209

GeoVision GV-SNVR0811

Captured

Directory traversal on the web server read /etc/passwd straight off the box, handing us the root hash. exploit-db/45065

Fortinet FortiGate

Captured

Identified by its admin-page favicon, then opened with the FortiOS SSH backdoor. The flag was the MD5 of the partition label from execute disk list. exploit-db/43386

Control4 controller

Captured

Logged in with the well-known default root password and read the flag off the SD card at /mnt/sd/Flag.txt.

Control4: Black Box 1

Captured

Same default credentials, different prize: the flag was the MD5 sum of /etc/init.d/c4server.

Mosquitto / MQTT

Captured

Subscribed to the # wildcard topic with the given iot:iot creds and waited. About thirty minutes of nouns later, the flag scrolled past.

The remaining hosts (a link-clicker relay, a D-Link camera, and an unnamed DVR) were mapped but left without flags.
